= Expected rejections (Idris2)

Every `*.idr` here is a negative control: it states something the grade kernel
must refuse. `tools/check-kernel-proofs.sh` checks each one against the built
`src/abi` package. It passes only if the file is refused, the error sits at
its `invalid` declaration, and the message matches the file's `-- EXPECT:`
line. A refusal for a scoping, parsing or path reason counts as a failure,
because then the control proves nothing.

[cols="1,3",options="header"]
|===
| Fixture | What it would smuggle in
| `HWMAnnihilates` | an annihilating zero in the occupancy algebra (resource-algebra C-4 / H-3)
| `LossWorstCase` | echo's alternatives read as max, i.e. loss treated as cost (S-2)
| `DriftExceedsPeak` | a run ending with more live state than its peak
| `TropicalIsNotMaxPlus` | L11's `TropCost` read as max-plus (it is min-plus)
| `CostIsOccupancy` | an L13 run charged the sum of its peaks, as if the boundary reclaimed nothing (occupancy-types R-6)
| `DriftIsPeak` | drift identified with peak: "a boundary never reclaims" (occupancy-types R-6)
| `WorstCaseIsCheapest` | L11's MaxPlus worst case charging the cheaper branch
| `InitialOverMaximum` | an L13 private memory certified by an empty run although its initial allocation is unbounded by its maximum
| `UnprojectableChoice` | K-CUT-LOSS without the Projectable side-condition (choreographic-types K-7)
| `InconsistentCut` | K-CUT-LOSS without the Consistent side-condition (choreographic-types K-7)
|===

`HWMAnnihilates`, `LossWorstCase` and `DriftExceedsPeak` mirror resource-algebra
`tests/reject/*.agda`; `CostIsOccupancy` and `DriftIsPeak` mirror occupancy-types
`tests/reject/*.agda`; `UnprojectableChoice` and `InconsistentCut` mirror
choreographic-types
`tests/reject/*.agda`, all at the pins in
`scripts/fetch-siblings.sh`.
