== Purpose

Written record of the 2026-05-31 session that reconciled two parallel
codegen efforts and closed Phase 0. Companion to `CHANGELOG.md` (what

Zig experiment explored in parallel.

== Context: two codegen efforts

Phase 0 gate 2 required an in-tree `.twasm -> .wasm` producer
(link:../../PRODUCTION-PATH.adoc[PRODUCTION-PATH.adoc] §"What advancing
to Phase 1 requires"). Two independent attempts converged in the same
window:

* **Rust** — `crates/typed-wasm-codegen` (`tw build`), a workspace
  sibling of `typed-wasm-verify` emitting wasm via `wasm-encoder` and
  round-tripping through `verify_from_module` in-process. Host language
  fixed by link:../../decisions/0004-codegen-host-language.adoc[ADR-0004]
  (status *Proposed*). Landed via PR #134 (example 01), #139 (multi-module
  L10 boundary), #141 (example 03 L7-L10 + wasm `name` section), #126
  (human-readable errors). **This is the canonical producer.**
* **Zig** — `src/codegen/` (`twasmc`), a single-file lexer ->
  recursive-descent parser -> layout -> wasm emitter, proposed in PR
  #136 (draft). Same "toolchain available in CI" rationale as ADR-0004,
  but a different host language.

ADR-0004 pins the producer to Rust (same toolchain as the verifier;
`wasm-encoder`/`wasmparser` already pinned; the verifier's own carrier
encoders are reused so emitted bytes provably match what the verifier
accepts). The Zig `twasmc` is therefore redundant and off-decision.

== Decisions taken this session

. **#136 (Zig `twasmc`) closed as superseded.** No `src/codegen/`, no
  vendored golden `.wasm` fixture, and no Zig toolchain dependency land
  in-tree. The closed PR retains its diff for the historical record.
. **One piece salvaged — the standalone verifier CLI.** The verifier
  crate was lib-only; `tw build` self-verifies but nothing verified a
  pre-existing `.wasm`. PR #143 adds `crates/typed-wasm-verify/src/bin/
  tw-verify.rs`: `tw-verify <module.wasm>` runs structural validation ->
  L7/L10/L13 ownership -> L2 access-site / L15 capability passes. It is
  host-language-neutral and complements the Rust producer; validated
  against `tw build` output.
. **Status drift reconciled (PR #144).** `main`'s CHANGELOG recorded
  gate 2 discharged by #134, but `AUDIT.adoc`, `STATE.a2ml`,
  `docs/PRODUCTION-PATH.adoc`, and `docs/wiki/Phase-0-Status.md` still
  read "2 of 3 gates met / codegen v0 outstanding". All four were
  reconciled to "3 of 3", crediting the Rust producer and noting
  ADR-0004 is *Proposed* (so the host-language decision is not
  over-claimed as final).
