== What this handoff is about

Both producers need to start emitting `typedwasm.access-sites`. The
verifier already consumes the carrier; without producer emission the
L2-per-instruction enforcement cannot fire on emitted bytes (only the
L2-spec / L3-L6 / L15-A/B halves are carrier-backed today).

== The blocker (same in both repos)

Today the IR / codegen pipeline has typed access at the **type**
level — both typecheckers (`lib/borrow.ml` in AffineScript;
`src/ephapax-typing/` in Ephapax) resolve `(region, field)` at
typecheck. By the time codegen emits `i32.load offset=N` /
`i32.store offset=N`, the semantic `(region_id, field_id)`
annotation is gone — codegen recomputes offsets from a local layout
table and the binding is lost between the two passes.

Without `(region_id, field_id)` available at each emit site, there is
nothing to put in the carrier entries.

=== Three resolution options (same shape in both repos)

. **IR annotation** — add resolved `(region_id, field_id)` to the
  typed-access AST/IR variant. Populated by the typechecker, consumed
  by codegen. Cleanest; minimal coupling between the two passes.
. **Side-table** — typechecker produces `Map<expr_id, (region_id,
  field_id)>`, codegen consults during emission. Less invasive to
  AST/IR shape; adds a parameter to the codegen entry function.
. **Re-resolve at codegen** — duplicate typechecker resolution
  logic in codegen. Code smell; avoid unless 1 + 2 are both blocked
  (e.g. by AST stability constraints).

The owner has not selected between 1 / 2 / 3. Both producers should
adopt the **same** option for parity, so propose one and confirm
before implementing.

== The encoder (~25 LOC, mechanical)

Wire format per typed-wasm proposal 0002 §"Wire format":

[source]
----
u16le   version              (= ACCESS_SITES_VERSION = 1)
u32le   entry_count
for each entry (strictly ordered by (func_idx, byte_offset)):
    u32le  func_idx
    u32le  instruction_byte_offset
    u32le  region_id
    u32le  field_id
----

Encoding option B (LEB128 per field) per proposal 0002 §"Wire format"
measurement (~5B/access, ~1.1% module overhead).

The encoder is straightforward — pattern-match on the precedents:

* AffineScript: extend `lib/tw_section.ml` / `lib/tw_section.mli`
  with `Encode.access_sites : (int * int * int * int) list -> bytes`.
  The forward-compat slot is already declared in the `.mli` header
  (refreshed in affinescript#468).
* Ephapax: add an `encode_access_sites_section` helper alongside the
  inline `typedwasm.ownership` encoder in `src/ephapax-wasm/src/lib.rs`.

== Coordination notes

* **Both producers must adopt the SAME threading option** (1 / 2 / 3
  above). Do not let one repo ship IR-annotation while the other
  ships side-table; the carrier wire format is shared so the
  producer-internal mechanism should be too where reasonable.
* **The encoder is the easy half.** Don't be tempted to land
  `Encode.access_sites` first as a "minimal slice" — without the
  threading, it has no feeder. The dead-code lint will catch it
  in Rust; OCaml is more forgiving but it still wastes a PR.
* **Field IDs must be stable across producers consuming the same
  shared schema** (cross-module case). When a region is imported
  from another module, the importer's `field_id` numbering must
  match the exporter's — this is what the typed-wasm verifier's
  `verify_access_sites_from_module` checks via the
  `typedwasm.regions` cross-reference. If the typechecker assigns
  field IDs from a per-module counter, the cross-module case will
  fail. Confirm the ID scheme is shared-schema-aware before relying
  on it.
* **No new wire-format proposals.** This is implementation of
  already-accepted proposal 0002 / ADR-0003. If the threading work
  surfaces a wire-format gap, file a proposal-0002 amendment issue
  rather than improvising.

== Sequencing recommendation

. **Decide the threading option (1/2/3) with the owner first.** Do
  not start coding before this is settled.
. Pick **one repo** to prototype in. Ephapax (Rust) is probably
  faster to iterate because the lint catches unused threading
  early; AffineScript (OCaml) is more forgiving but requires
  reading more code.
. Land the threading + encoder + assembly + tests as a single PR
  in the chosen repo.
. Mirror the same approach in the other repo as a second PR.
. Land at least one cross-repo differential-corpus fixture in
  typed-wasm (`crates/typed-wasm-verify/tests/fixtures/c5_real/`).
. Update `LEVEL-STATUS.md` L3-L6 row + Open-gating item 1 to mark
  producer-side access-sites emission ✅.
